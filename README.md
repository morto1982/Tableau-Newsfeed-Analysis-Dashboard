# Newsfeed Analysis Dashboard | Tableau

## Project Overview

This project presents an interactive Tableau dashboard developed as a data analytics case study to explore newsfeed activity and user engagement patterns from January to May 2023.

The dashboard provides visual insights into posting activity, content distribution, likes, comments, and user engagement indicators.

## Project Objectives

- Analyze monthly posting activity and average likes per post.
- Identify the most frequently published post subtypes.
- Compare post subtypes by total likes and comments.
- Examine user engagement indicators.
- Enable interactive exploration through date and post subtype filters.

## Tools and Technologies

- Tableau
- Data Visualization
- Dashboard Design
- Exploratory Data Analysis
- KPI Monitoring

## Dashboard Components

1. **Monthly Post Activity & Average Likes** — Monthly posting activity and average likes per post.
2. **Subtype Popularity Measured in Likes** — Comparison of content categories by likes.
3. **Subtype Post Distribution** — Distribution of posts across content subtypes.
4. **Newsfeed User Engagement** — Summary of user engagement indicators.
5. **Subtype Popularity Measured in Comments** — Comparison of content categories by comments.
